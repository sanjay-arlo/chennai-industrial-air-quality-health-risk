# Optional Python Layer

Baseline workflow: **Excel → SQL → Power BI → Decision**.

Use Pandas + NumPy where EDA, anomaly detection, pollutant relationships, repeated quality checks or automation adds value.

Suggested use here:
- Pandas: monitoring-data profiling and zone exposure analysis.
- NumPy: percentile thresholds, anomaly flags and numerical sensitivity checks.

Python remains optional; governed KPI definitions belong to SQL and Power BI.
